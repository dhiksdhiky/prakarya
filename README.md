# Prakarya (2021 - 2026)

*Verba volant, scripta manent.*

Repo ini saya bikin buat nyimpen arsip "prakarya" dan alat bantu kerja yang pernah saya buat waktu awal-awal kerja di KP2KP Pinrang / KPP Pratama Parepare (2021) sampai masa tugas belajar.

Berangkat dari background non-IT, awalnya saya ngulik hal-hal kaya gini murni karena di kantor banyak kerjaan yang sifatnya berulang (repetitif). Kalau pas antrean lagi ramai, kerjaan template kaya gitu rawan banget bikin human error. Jadi daripada capek ngerjain manual terus, saya coba cari cara biar kerjaannya bisa lebih cepat dan akurat.

Isi repo ini rencananya bakal saya cicil bertahap sesuai urutan waktu saya belajarnya dulu:

### 1. [01-vba-excel](./01-vba-excel) (2021 - 2022)
Kumpulan project waktu pertama kali kenal dan ngulik VBA Excel (zaman sebelum ada AI, masih modal cari-cari di YouTube, artikel web, sama Stack Overflow).
- **[01-helper-spt-1770](./01-vba-excel/01-helper-spt-1770):** Excel helper buat bantu asistensi SPT Tahunan 1770 & E-Form (hitung otomatis PP 23 dua arah, bikin file CSV & PDF lampiran sekali klik, simulasi goal seek, sampai ambil token dari web internal).
- **02-inventaris-kp2kp:** *(menyusul)* Aplikasi pencatatan stok barang & souvenir kantor pakai UserForm.
- **03-formulir-tpt-otomatis:** *(menyusul)* Alat bantu cetak belasan jenis formulir permohonan WP otomatis beserta daftar syaratnya.
- **04-billing-dan-pengantar-pos:** *(menyusul)* Rekap kode billing bulanan dan cetak label alamat amplop pos.

### 2. `02-web-internal-mysql` *(menyusul)*
Project waktu pindah ke seksi PKD dan Sekretariat. Mulai mentok sama batasan Excel dan belajar bikin web internal sederhana pakai database MySQL.

### 3. `03-powerbi-analytics` *(menyusul)*
Dokumentasi waktu mulai fokus ngulik visualisasi data dan bikin dashboard pakai Power BI.
